🔑 One secret: the extension never talks to the worker.
It only talks to Supabase. The worker only talks to Supabase.
The message board connects them. Simple!

Two separate companies, two separate bills 💳

🌿 Supabase — The Message Board

One company, one account, one login.

🔐 Login & AuthChecks who you are. Only you can see your jobs.
🗄️ Job Board (database)A table of jobs: waiting → downloading → done. Everyone reads & writes here.
📦 Storage (optional)A locker for finished video files.

🚂 Railway (or Fly.io) — The Worker

Another company, a different account, a different login.

🤖 Long-running workerA program that runs 24/7, waiting for jobs.
⬇️ yt-dlpFetches the video from YouTube etc.
🎞️ ffmpegTurns it into the file you want (mp3, mp4…).

⏱️ What happens, step by step

1
🧩
You click the extension button. It asks Supabase: "please add a job: download this video". Supabase checks you are logged in. ✅
2
🗄️
The job appears on the board with status waiting.
3
🤖
The worker on Railway notices the job. It sets status to downloading and starts yt-dlp + ffmpeg. ⏳ This can take a while!
4
🗄️
When finished, the worker writes back: status done + a link to the file (or uploads it to Supabase Storage). If it failed: status failed.
5
🧩
The extension keeps asking Supabase: "is it done yet?" 🔁 Every few seconds.
6
🎉
Board says done → the extension shows you the file / download link. failed → it shows a sad message. That's it!

💡 Why two companies? The message board (Supabase) is great at quick lookups & logins.
The worker (Railway) is great at long, heavy jobs like downloading a whole video.
Each one does what it's best at — they just chat through the board.
